# 编辑器操作手册

打开 `http://127.0.0.1:8765/`。左侧是图表清单，右侧每张图一块。

## 改数字的四种方式

| 方式 | 操作 | 适合 |
|---|---|---|
| 表格 | 下方表格里直接改，失去焦点即生效 | 精确输入 |
| 拖单点 | 折线图上按住圆点上下拖 | 微调一两个点 |
| 拖整条线 | 按住线本身（不是点）上下拖 | 整组平移 |
| 拖柱子 | 条形图上按住柱子上下拖 | 条形图 |

拖动过程中鼠标旁会有一个白框显示当前数值，例如 `SDR：28.63 dB`。表格里会同步更新。

## 两条线挨太近怎么办

点该图上的 **「高级选择」**：

1. 选模型（或"全部模型"）；
2. 选手势：「拖动单个点」或「拖动整条线」。

锁定后：
- 未被选中的曲线变暗（18% 透明度）且完全不再响应拖动；
- 手势被限定为选中的那一种（选"拖点"时线不能拖，选"拖线"时点不能拖）；
- 选中的曲线会轻微高亮（点变大、线的响应区带淡蓝）。

取消勾选即恢复自由拖动。

## 写盘

| 按钮 | 范围 | 编译 PDF |
|---|---|---|
| 每张图的「只保存这张图」 | 只重跑这张图的脚本 | 永不 |
| 「运行 / 重绘」 | 全部图 | 看勾选 |
| 「一键绘图 → 写入论文」 | 全部图 | 看勾选 |

一次点击后弹窗会列出实际写入的文件。

## 后悔药

| 按钮 | 作用 | 可再撤销吗 |
|---|---|---|
| 图上「↶ 回退」 | 撤销这张图的上一次改动 | 不会（被消费掉） |
| 顶栏「历史修改记录」 | 列出每条改动的时间、图名、具体是哪个格子从 X 变成 Y | 每条可"回退到此"（连同之后的一起回滚） |
| 图上「↺ 恢复原始」 | 回到实测数据并立刻重画这张图 | 会记入历史，可用回退撤销 |
| 顶栏「恢复默认」 | 全部图回到实测数据 | 会记入历史 |

历史最多保留 40 条，随浏览器保存在本机。

## 备份

- **导出 JSON**：把当前全部数字存成文件。建议改完一轮就导一份进仓库（例如 `figure_editor/snapshots/`）。
- **导入 JSON**：还原。
- 浏览器缓存会被"清除浏览数据"、无痕窗口、换电脑抹掉，**不要把它当唯一副本**。

## 精度与提示

- 数值默认保留两位小数（表格里可以输入更多位）。
- 拖动时纵轴不随动（避免坐标轴跳动导致拖不准），松手后重绘并重新自适应。
- 条形拖动时，柱子上的数值标签和误差棒会暂时隐藏，松手后在新位置重画。

## 常见疑问

**Q：改了数字但论文里的图没变？**
A：数据改动只在浏览器里；要写进图片必须点「只保存这张图」（或一键绘图）。确认本地服务在跑。

**Q：能改坐标轴范围、颜色、图例吗？**
A：不能，也不应该。这一层的设计边界就是"只换数字"，样式由原脚本决定。

**Q：能加新图吗？**
A：给脚本插 hook 并登记到 `editor_config.json`，再跑一次 `seed.py`。编辑器会自动补上新图，已有改动不受影响。

**Q：为什么我的改动在另一台电脑上没有？**
A：数据在本机浏览器里。用「导出 JSON」转移到另一台，再「导入 JSON」。
