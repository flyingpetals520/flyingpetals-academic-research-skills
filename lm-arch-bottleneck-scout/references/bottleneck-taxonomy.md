# 瓶颈五分类与启发式提问清单

## 使用方法

拿到目标组件 X（一条注意力、一套残差、一个优化器、一个嵌入层……），先按五类来源逐项过筛，再用提问清单把模糊不满变成可归因的瓶颈描述。每个瓶颈最终必须落成 SKILL.md 中的严格句式：当【条件】时，【X 的哪个量/性质】导致【可观测失败或代价，带量级】。

## 五类瓶颈来源

### A. 表达瓶颈（Expressiveness）
结构本身"说不出"某些函数。
- 典型信号：某个量为固定值/全体共享/均匀分布（固定残差权重、头级标量门控、固定稀疏模式）；某个性质被约束掉（实数谱、非负门控）。
- 案例：KDA 发现 Gated DeltaNet 的头级标量衰减使所有维度同速遗忘 → 逐通道门控；CKDA 进一步发现非负对角门使转移谱留在实轴 → 无法表达旋转动力学。
- 提问：X 里哪些量是固定/共享/均匀的？放开成可学习/独立/分层会怎样？X 的哪个硬编码约束其实可以软化？

### B. 稳定性瓶颈（Stability）
改造破坏了好性质，训练在规模上去后崩。
- 典型信号：恒等映射被破坏、范数不守恒、信号随深度/宽度放大、初始化时机制退化成病态。
- 案例：HC 的自由连接矩阵破坏恒等映射，深层信号放大数百倍 → mHC 用双随机流形把放大压回 ~1.6×；MSA 的 indexer 冷启动乱路由 → 40B token 全注意力 warmup 用 KL 对齐再切稀疏。
- 提问：X 保恒等映射/范数守恒吗？放大系数随深度怎么变？训练早期和晚期 X 的行为差多少？第 0 步时 X 退化成什么？

### C. 成本-复杂度瓶颈（Cost）
成本公式里某项随规模恶化，或二阶成本被忽略。
- 典型信号：O(L²)/O(N³C)/O(Ld) 级增长；被省掉的主成本之外冒出新的热点（打分、选择、通信）。
- 案例：xHC 发现 residual mapping 生成随 N 立方增长 → 稀疏写回只更新 16 流中的 4 流；DoSA 发现 DSA 省掉主注意力后 indexer 全量打分成为新关键路径 → 证书界跳过无望候选。
- 提问：把 X 的成本公式完整写下，哪项随规模涨最快？省掉主成本后，下一大的成本是什么（选择？通信？不规则访存？）？FLOPs 省了，wall-clock 省了吗？

### D. 硬件匹配瓶颈（Hardware mismatch）
理论上省钱，硬件上赚不到。
- 典型信号：张量核利用率低、访存不规则、kernel 无法融合、并行切分困难。
- 案例：MSA 之前的细粒度稀疏打爆张量核 → 块级选择 + exp-free top-k + KV-outer 布局；AttnRes 的 O(Ld) 层输出驻留 → 两阶段推理 + 跨 stage 缓存把每 token 每 layer I/O 压到 5.5d；mHC 的 Sinkhorn 迭代 → mHC-lite 砍迭代数。
- 提问：X 的访存模式规则吗？张量核吃得满吗？能不能融合 kernel？在 TP/PP/EP 切分下通信怎么变？

### E. 尺度外推瓶颈（Scaling）
小规模成立，规模/长度上去失效或收益递减。
- 典型信号：N=4 到 N=16 收益递减（xHC）；128K 内无损、1M 漏检（压缩类注意力）；loss 降了下游不涨（蒸馏/转换类工作）。
- 案例：mHC 把 HC 从"小模型可行"推到 27B 稳定；MSA 的质量声明只在 109B/3T 预算下验证。
- 提问：X 的收益-成本曲线在哪个规模点开始变平？失败是突然出现还是渐进的？小规模代理指标（CE loss）和大规模指标（下游任务）一致吗？

## 18 条启发式提问清单

对组件 X 依次自问：

表达侧
1. X 的每个"常数/固定结构"背后，是数学必然还是工程惯例？
2. 如果把 X 的某个标量升级为向量/矩阵/注意力，表达力买到什么、付出什么？
3. X 的限制属于哪一类：信息容量、选择粒度、还是归纳偏置？

稳定性侧
4. X 是否破坏恒等路径？破坏后靠什么兜底（归一化、门控初始化、流形约束）？
5. X 在初始化时退化为什么？这个退化态是否健康（参考 AttnRes 零初始化伪查询 → 均匀平均）？
6. 训练早期 vs 晚期，X 学习的对象是否漂移（MSA indexer 追移动目标）？

成本侧
7. X 的渐近复杂度里，常数项里藏着什么（每 token 每 layer I/O、kernel 启动次数）？
8. X 消灭的旧瓶颈会不会留下"遗产成本"（如跨 stage 通信、checkpoint 额外驻留）？
9. 给 X 做 profiling 的话，第一热点会出现在哪里？有没有"理论上不存在"的热点（top-k 选择、Sinkhorn 迭代）？

硬件侧
10. X 的数据流是规则的 dense 块，还是 gather/scatter 主导？
11. X 需要的专用 kernel 复杂度多高？社区已有原语可复用吗（FlashAttention、chunkwise 递归、radix top-k）？
12. X 在推理路径上增加的是计算还是访存？两者在当前 GPU 代际哪个是瓶颈？

尺度侧
13. X 的失败阈值（context 长度、N、深度、参数量）是多少？是什么量达到临界？
14. X 的收益是"质变"（解锁新能力）还是"量变"（同 loss 省算力）？接力的下一棒更可能从哪来？
15. 上一代方案依赖的假设，在 X 的新条件下还成立吗（如 V4 中 MLA 的 RoPE 正确性论证不迁移到序列压缩表示）？

谱系侧
16. 把 X 与上一代并排，X 改掉的第一个量是什么？通常那就是上一代瓶颈的化身。
17. X 的消融里，作者主动砍掉的变体（AttnRes 的 sigmoid、input-dependent query）暗示了什么？
18. 如果 X 免费（零开销），还会被什么限制？——那个限制就是下一代瓶颈的候选。

## 常见反模式（这些不是瓶颈）

- "效果不够好 / SOTA 不够高" —— 不可归因，退回提问清单。
- "训练不稳定"（无量级、无条件）—— 同上。
- "想要更高效的注意力" —— 这是愿望；瓶颈是"哪一步、在什么长度、贵几倍"。
- 把工程未优化当成算法瓶颈（先确认没有现成 kernel 能白拿收益）。
