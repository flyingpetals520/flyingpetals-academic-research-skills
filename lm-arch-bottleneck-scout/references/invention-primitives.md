# 解决动作原语库（十二条）

每条原语：定义 → 何时用（对应瓶颈类型）→ 先例（详见 case-library.md）→ 已知代价/风险 → 常用组合。

## P1 参数化（把固定的量放开）
- **定义**：把结构中的常量/均匀量升级为可学习、输入依赖、逐通道的量。
- **何时用**：瓶颈 A 表达类，且现存量的"固定/共享"是主要限制。
- **先例**：AttnRes（固定残差权重→逐层 softmax 权重）；KDA（头级标量门→逐通道对角门控）；DSA（块级选择→token 级打分）。
- **代价**：参数与计算增加；可学习量的初始化决定训练早期稳定性（必须配 P9 初始化手术）。
- **组合**：P1 几乎总要配 P9（如 AttnRes 伪查询零初始化）。

## P2 约束化（加结构约束恢复性质）
- **定义**：不放开自由度，而是把自由度限制在一个保持关键性质的流形/集合上。
- **何时用**：瓶颈 B 稳定类——自由化已导致性质破坏。
- **先例**：mHC（连接矩阵投影到双随机矩阵 Birkhoff 流形，Sinkhorn-Knopp 可微实现，恢复恒等映射）。
- **代价**：投影/迭代本身有开销（mHC-lite 专门削减 Sinkhorn 迭代数）；实现复杂度。
- **要点**：约束要使"好性质"成为投影的吸引子，而非靠调参碰运气。

## P3 升维/加流
- **定义**：把单一状态拆成多个并行状态（多流、多头、多专家、多频段）。
- **何时用**：状态容量本身是瓶颈（残差流、RNN 记忆、嵌入带宽）。
- **先例**：HC（1→N 残差流）；VWN（隐状态"虚拟加宽"）；MoE（FFN 参数化加流）。
- **代价**：跨流信息供给摊薄（xHC 的 write-back 瓶颈）、混合成本随 N 上涨 → 通常要配 P4。
- **要点**：加流之后立刻问"每个新流拿到的新信息是否不同"——答案是否定的话，新流是冗余。

## P4 稀疏化
- **定义**：让每个查询只激活全部候选的一个子集，粒度从粗到细：层间→块→token。
- **何时用**：瓶颈 C/D，全量计算或全量访存不可承受。
- **先例**：NSA（可训块稀疏）→ DSA（token 级）→ MSA（按 GQA 组独立选块）；MoBA（MoE 式路由）。
- **代价**：选择本身成为新成本（DoSA 攻击的正是这个）；压缩/选择有损 → 配 P6 混合化兜底质量。
- **要点**：粒度每细一档，选择器成本涨一档——先确认选择器省下的钱大于它自己的开销。

## P5 压缩化
- **定义**：把一组 token/矩阵/维度折叠成更小的表示，再在其上计算。两条路线：**先压缩再选择**（V4 CSA：4:1 压缩后 top-k）与**先选择再精确**（MSA：原分辨率选块后精确注意力）。
- **何时用**：瓶颈 C/E，缓存或序列长度本身撑爆。
- **先例**：MLA（KV 潜变量压缩）；CSA/HCA（序列维压缩 4:1 / 128:1）；NSA 压缩分支。
- **代价**：有损不可逆（压缩块内无法再拆）；远程细节丢失 → 配滑动窗口/注意力 sink 保局部。
- **要点**：压缩率是质量-成本曲线上的旋钮，混合架构=不同层用不同旋钮档位（V4 交错 CSA/HCA）。

## P6 解耦化
- **定义**：把耦合在一个模块里的两种职能拆开，各自优化。
- **何时用**：一个模块身兼二职且两者的最优形态冲突。
- **先例**：DSA（选择器从主注意力解耦出 Lightning Indexer，打分维度/精度与主计算独立）；MSA（index branch 与 main branch 两分支）；Muon 谱系中嵌入/头留在 AdamW、矩阵参数走 Muon。
- **代价**：多一个模块就多一个自身的瓶颈；解耦界面要保持语义一致（MSA 用 KL 对齐 index 与 main）。
- **要点**：解耦的判断标准——两个职能的最优粒度、最优精度、最优更新频率是否不同。

## P7 混合化
- **定义**：异质组件按层/按位交错，各取所长。
- **何时用**：没有单一组件在所有长度/任务上都最优。
- **先例**：Kimi Linear 3:1 KDA:MLA（线性层扛长程、全注意力层保精确召回）；V4 CSA/HCA 交错；Qwen3-Next 混合线注意力。
- **代价**：系统复杂度（两种 kernel、两种 cache 管理）；比例成为超参。
- **要点**：混合比例本身是可分析对象——Kimi Linear 论证 3:1 是效率-精度平衡点。

## P8 缓存/复用
- **定义**：把重复计算或重复传输的结果存起来复用。
- **何时用**：瓶颈 C/D，流水线/多查询间存在冗余。
- **先例**：AttnRes 跨 stage 缓存（通信从 O(C) 降到 O(P)）；GVR 用上一步 top-k 做时序预测；HySparse 复用 dense 层 KV。
- **代价**：缓存一致性、额外显存驻留。
- **要点**：问"同一信息在本组件内被重复搬运/计算了几次"。

## P9 初始化/渐进手术
- **定义**：不动架构，通过初始化或训练日程让机制"从健康退化态渐进苏醒"。
- **何时用**：新机制冷启动病态（随机选择器、未训练门控）。
- **先例**：AttnRes 伪查询零初始化（起点=均匀平均）；mHC/xHC 门控初始化 0.01（起点≈静态）；MSA indexer warmup（先全注意力 KL 对齐 40B token 再切稀疏）；GQA 从 MHA checkpoint uptrain。
- **代价**：多一段预热预算；预热比例随场景变化（MSA-CPT 中 warmup 占 10% vs MSA-PT 1.3%）。
- **要点**：先写出"第 0 步的退化形态"，再决定初始化让它退化成什么。

## P10 硬件协同设计
- **定义**：算法形状按硬件特性（张量核、访存层级、kernel 可融合性）重塑。
- **何时用**：瓶颈 D——理论收益兑现不了。
- **先例**：MSA（exp-free top-k、KV-outer 布局）；AttnRes 两阶段推理（Phase1 批量、Phase2 融合）；KDA 专用 DPLR chunkwise 算法；DSA indexer FP8 + MQA。
- **代价**：kernel 工程量大、换硬件代际要重做。
- **要点**：报收益时区分 FLOPs 倍数与 wall-clock 倍数（MSA：28.4× vs 14.2×），前者常被引用，后者才是钱。

## P11 数学证书/界
- **定义**：给近似或剪枝配上"不出错"的证明界，把启发式变成有保证的精确。
- **何时用**：加速手段必须零质量损失（部署红线）。
- **先例**：DoSA（候选拒绝证书：种子集给阈值下界 + 头界，跳过无望候选且 top-k 结果逐 token 一致）；mHC 双随机约束保证非扩张。
- **代价**：证明适用范围窄（对分布/几何有假设）；保守时收益打折。
- **要点**："无损"是市场最强卖点之一，优先找只需证据即可拒绝候选的问题结构（top-k、剪枝、早退）。

## P12 换轴
- **定义**：在所有人都优化 A 轴时，改去优化被忽视的 B 轴。
- **何时用**：A 轴拥挤且边际递减。
- **先例**：SQA（MQA/GQA 减 KV 头减的是带宽不减 FLOPs → 减 Query 头直接砍 FLOPs）；VWN（不真加宽模型，把"虚拟宽度"加在嵌入/残差流上）；xHC（把扩展轴从深度/宽度换成残差流宽度 N）。
- **代价**：新轴往往缺生态（kernel、并行策略、评测惯例都要自己铺）。
- **要点**：换轴后第一件事是论证"新轴也是轴"——即沿它 scaling 有收益证据（N=1→4 的收益正是 xHC 的立项依据）。

## 选择原语的经验规则

1. 表达瓶颈（A）→ P1/P3/P12；稳定瓶颈（B）→ P2/P9；成本瓶颈（C）→ P4/P5/P8；硬件瓶颈（D）→ P10/P8/P11；尺度瓶颈（E）→ P5/P7/P9。
2. 一个主原语解决瓶颈，一个兜底原语保护质量/稳定，是 2025-2026 高产论文的标配结构。
3. 新原语组合前，先查 case-library 中同原语先例的"已知代价"列——你的新瓶颈大概率就写在别人的代价列里。
