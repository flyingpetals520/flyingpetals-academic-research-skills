# 写作戒律（OscillaFormer CVPR 投稿版）

> 正文与附录写作/修改的硬性检查清单，每次改动论文后逐条自查。
> （2026-10-09 作者确认；2026-11-14 增补句子机械结构）

## 一、叙事纪律

1. **不写负面结果**：不呈现对我们不利的结果、中间失败与试错过程；
   "先试了 X 不行、换成 Y"式的叙述一律不写。

2. **不过度道歉、不主动认错、不反向改口径**：不写"我们没做到／可能不行／仅供参考"
   这类自我削弱表述；不为了显得诚实而主动承认负面事实。
   - 判断标准：如果问题真实存在、审稿人一定会抓住（"直接撞枪口"），
     **必须正面解决或圆场化解**（改框架、改叙事口径、补证据），而不是在
     Limitations 里等坦白。

3. **不写成实验报告式流水账**，不写 changelog 式自白（"后来我们又改了……"）。

4. **不堆砌 md 式内容**：正文不出现分点式清单堆砌、时间戳、任务条目等，
   该用连贯段落表达。

5. **数字克制**：正文不堆砌大量数字；**同一句话不出现大量数字**——
   关键结论保留少量数字，细节数字交给表格。

## 二、公式与术语

6. **公式保持纯数学**：公式里不要塞大量 \text/文字；原理说明放在公式外的
   文字段落里讲清楚。
   - 扩充（2026-10-15 作者重申）：**散文里禁止直接内嵌** 小于/大于/不等号
     （<、>、≤、≥）、约等号（≈、$\sim$）、区间式（$[a,b]$、$x \in [a,b]$）、
     集合式（$\{x : \dots\}$）、以及一步能说清的简单公式（如
     $\mathrm{SNR}(s)=10\log_{10}(\cdot)$、$\eta=0.05$、$\mathrm{BT}=0.3$）。
     一律改自然语言："below 6\,dB"、"between $-6$ and $+6$\,dB"、"about
     14,300"、"five percent"、"a time-bandwidth product of 0.3"。
     只有展示公式（equation 环境）保留数学；其后的 where 从句用文字解释符号。
     表格单元允许简写。

7. **消灭黑话与未定义缩写**：首次出现的缩写必须展开；前文没出现过、
   审稿人不可能懂的代称一律先展开或改用大白话。
   一句话里不要堆太多缩写导致信息密度过大，该大白话时用大白话。
   - 例外（2026-10-15 作者补充）：**大家都知道的标准缩写不要展开**——
     通用方法/领域基础或论文中作为模型名直接
     使用的，保持裸用。
   - 但要展开的确包括：**可能不认识的领域专有缩写**（如 BS/UE/LOS——
     审稿人未必熟悉术语；在首次出现的表注或正文补齐全称），
     以及真正有歧义或冷门的（LTI、IIR、ERF 等）。

8. **括号不装增补信息**：配置/设置类细节
   （如 "(batch size 20, no gradient checkpointing)"）写在括号里不是规范的
   学术写作。处理顺序：① 有必要 → 顺进自然语言（"at a batch size of 20
   without gradient checkpointing, ..."）；② 没必要 → 直接删除或移到附录。
   括号只留给：引用、缩写全写、极短的同位语限定。

## 三、句子机械结构（2026-11-14 新增）

9. **连接词与分号过密必须查**：一句话里 `and` 出现 3 次及以上，或出现分号，
   或 `which/while/where/that` 等从句标记叠加，视为"连接过密"。
   典型形态：`A ... and B ..., which ..., and ..., which ...`。
   - 判断标准：不是看到 and 就拆，而是看句子是否有两个以上并列主张、
     两层以上从句、或分句之间没有清楚的主从关系。
   - 分号在一句里原则上不超过 1 个；出现分号说明两个独立判断被硬塞进一句，
     优先考虑拆句。

10. **碎句并列也要查**：连续 3 句以上、每句都很短（<14 词）且每句都塞入
    引用/数字/任务名，属于"信息密度过高的碎句并列"，应合并或改写为
    有主从层次的句子。长句与碎句是两个极端，都要避免。

11. **长句处理采用"同义拆句"**：拆句不是按字数切，而是在保持语义等价的前提下
    按逻辑关系拆（因果、转折、定义、证据、条件）。拆完必须满足：
    - 不新增、不删除任何主张或限定条件；
    - 每句有明确主语，避免悬空的 This/It；
    - 术语、符号、引用编号不变；
    - 拆后逻辑层次比原句更清楚，而不是变成流水账。
    如果拆完语气或重点发生变化，恢复原句，改用压缩或调整从句结构。

12. **可接受的长句**：单一主张、从句层次清楚、没有分号、and 不超过 2 个的
    长句可以保留；不要为了"短"而破坏论证节奏。

## 四、执行方式

- 每次改完论文：逐句通读一遍，对照本清单自查。
- 拿不准是否属"负面"时，用审稿人视角判断：是否给攻击点？
  会给 → 解决/圆场；不给 → 可保留。
